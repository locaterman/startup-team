# Второй этап: исправления F2/F6

Завершён 22 октября 2026. Исправления и браузерные проверки выполнены 21 октября, оформление завершено 22 октября. Область — отдельный localStorage-макет `design/prototypes/src/complete/`. Backend, рабочий frontend, схема и данные приложения этим этапом не менялись.

## F2 — сдача решения

- `submitSolution` отклоняет повтор для одной попытки и версии тестового до изменения данных. Исходная ссылка и события сохраняются.
- `availableTestVersions` исключает уже сданные версии текущей попытки, просроченные версии и версии до последующего критического обновления. UI использует этот список и для кнопки, и для формы.
- Кнопка «Отправить другое решение» удалена. При отсутствии доступных версий отправка не предлагается, существующее решение остаётся доступным.
- Обычное обновление может дать другую допустимую версию; новая попытка может сдать ту же версию заново. Правило API «одно решение на attempt/test_version» не расширялось. Ранее записанные дубли из старого макета не удаляются автоматически.

## F6 — исторические условия

- Компонент `AttemptHistory` показывает письмо, причину и полные название/описание/требования версии конкретной попытки.
- Заголовки отклика в списках и подробностях используют условия его текущей попытки. Переименование самой вакансии не переименовывает старую заявку.
- Отсутствующие исторические данные явно отмечаются; текущая версия не используется вместо потерянной. Общий отклик не получает выдуманную версию вакансии.

## Границы и следующий этап

Это проверка F2/F6, а не полного совпадения макета с сервером. Остальные пересечения из ревью (включая восстановление после critical, архив вакансии/сдачу тестового и принятие recruiter invitation при паузе) требуют согласования при интеграции. Макет остаётся демонстрационным localStorage-интерфейсом. API, cookie/CSRF, Idempotency-Key, If-Match и серверные DTO подключаются следующим этапом.

На этом этапе заново не запускались backend-тесты, полный мобильный/межбраузерный аудит и настоящий Telegram WebView. Геометрия изменённой истории просмотрена в текущем браузерном окне; прежние мобильные результаты не выдаются за новые проверки этих изменений. Коммиты, push и публикация не выполнялись.
